# Social Media Stress & Productivity Prediction

## Overview
This project is a Machine Learning based system that predicts:
1. Stress Level (Classification)
2. Productivity Score (Regression)

The project analyzes how social media usage, sleep patterns, exercise, and study/work habits affect stress and productivity.

---

## Dataset
Dataset includes:
- Age
- Daily screen time
- Social media usage hours
- Sleep hours
- Exercise minutes
- Study/work hours
- Productivity score
- Stress level
- Platform used

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## Machine Learning Models

### 1. Stress Level Prediction
- Model: Random Forest Classifier
- Type: Classification
- Evaluation Metric: Accuracy Score

### 2. Productivity Score Prediction
- Model: Random Forest Regressor
- Type: Regression
- Evaluation Metric: R² Score
