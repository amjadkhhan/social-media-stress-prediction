# 📱 Social Media Stress & Productivity Prediction

## 📌 Overview
This project is a Machine Learning based system that predicts:

1️⃣ Stress Level using Classification  
2️⃣ Productivity Score using Regression  

The project analyzes how social media usage, screen time, sleep habits, exercise, and study/work patterns affect stress and productivity.

---

# ✨ Features
✅ Data preprocessing and cleaning  
✅ Data visualization using graphs and heatmaps  
✅ Stress level prediction using Machine Learning  
✅ Productivity score prediction using Machine Learning  
✅ Accuracy score and R² score evaluation  
✅ Confusion matrix visualization  
✅ Actual vs Predicted comparison graph
